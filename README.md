# 忘年会 参加管理（PWA ＋ スプレッドシート）

スマホで声掛け状況と参加可否（一次会・二次会）を管理する PWA。データは Google スプレッドシートに保存され、GAS（Google Apps Script）が中継する。

```
PWA（GitHub Pages） ⇄ GAS（Webアプリ） ⇄ スプレッドシート
```

## セットアップ

### 1. スプレッドシートと GAS
1. Google ドライブで新しいスプレッドシートを作成する
2. 「拡張機能 > Apps Script」を開き、`gas/Code.gs` の内容を貼り付けて保存する
3. 関数 `setup` を選んで「実行」する（初回は権限の承認が必要）
   - 「声掛け」「参加管理」「開催情報」の3シートが作られる
4. 「デプロイ > 新しいデプロイ」から次の設定でデプロイする
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 表示された URL（末尾が `/exec`）をコピーする

### 2. PWA
1. `config.js` の `GAS_URL` に、手順 1-5 の URL を貼り付ける
2. このフォルダを GitHub Pages で公開する
3. 公開 URL をメンバーに共有する。スマホでは「ホーム画面に追加」するとアプリとして使える

### 3. スプレッドシートの共有
「共有 > リンクを知っている全員」を「編集者」にする（シートを直接編集したい人向け）

## 開催情報の編集
スプレッドシートの「開催情報」シートの「内容」列に書く。空欄の項目は画面に表示されない。項目は行を追加して増やせる。

## GAS を修正したとき
「デプロイ > デプロイを管理」で既存のデプロイを編集し、バージョンを「新バージョン」にして更新する（URL は変わらない）。

## 注意
- ログインがないため、URL を知っている人は誰でも閲覧・編集できる
- 名前は姓と名を分けて入力し、シートには「姓 名」（半角スペース区切り）で保存する。並び順は登録順
- 同じ姓名は登録できない
- メンバータブの「まとめて追加」で、クラスを選んで1行1人の「姓 名」を貼り付けて一括登録できる
- クラス（1組／2組）は各シート末尾の「クラス」列に保存する。画面上部で全員／1組／2組を切り替えられる
- 検索欄は全タブ共通で、名前の部分一致（姓名間のスペースは無視）
- 参加管理の集計タイルをタップすると、その会・その回答の人だけを表示する
- 同伴者（大人・子ども）は一次会・二次会ごとに「参加管理」シート末尾の4列へ保存し、参加のときだけ数える
- 声掛けの担当は「声掛け」シートの「担当」列に保存し、声をかけた人の初期値になる
- 参加管理タブの共有ボタンで、絞り込み中の一覧（なければ集計）をテキストで共有／コピーできる
- 操作内容は「変更履歴」シートに新しい順で記録する（ログインがないため操作した人は記録されない）
